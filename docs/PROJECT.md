# Product notes

## UX principles

SnapBrief is deliberately opinionated: one clear action, one clear result, minimal chrome.

The mobile interface uses a near-black canvas, a restrained lime accent, dense typography, and cards only where grouping helps comprehension.

## Roadmap

- streaming AI output
- editable action items
- share/export brief
- Supabase/Postgres sync
- authentication
- provider abstraction for Gemini/OpenAI-compatible endpoints
